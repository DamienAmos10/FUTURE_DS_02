# 📊 Telco Customer Churn Analysis Dashboard

## 🔍 Project Overview

This project focuses on analyzing customer churn behavior using the Telco Customer Churn dataset. The goal is to identify why customers leave, uncover retention patterns, and provide actionable business insights.

---

## 🎯 Objectives

* Analyze customer churn rate and trends
* Identify high-risk customer segments
* Understand customer lifetime and engagement
* Provide data-driven recommendations to improve retention

---

## 🛠 Tools Used

* **Power BI** – Data visualization & dashboard creation
* **Excel / CSV** – Data source
* **Power Query** – Data cleaning & transformation
* **DAX** – Measures and calculated columns

---

## 🧹 Data Cleaning & Transformation

The dataset was cleaned and prepared using Power Query:

* Removed null and duplicate values
* Corrected data types (numeric & categorical)
* Standardized Yes/No fields
* Created calculated columns:

  * Churn Value (0/1)
  * Tenure Group
  * Charge Category
  * Engagement Level
  * Customer Lifetime Value (CLV)

---

## 📊 Dashboard Features

The Power BI dashboard includes:

### 🔹 KPI Metrics

* Total Customers
* Churned Customers
* Churn Rate (%)
* Average Monthly Charges
* Total Revenue

### 🔹 Visual Analysis

* Churn by Contract Type
* Churn by Tenure Group
* Churn by Monthly Charges
* Churn by Internet Service
* Churn by Payment Method
* Engagement Level Distribution
* Revenue Loss Analysis

### 🔹 Interactive Filters

* Gender
* Senior Citizen
* Contract Type
* Internet Service
* Payment Method

---

## 📈 Key Insights

* Month-to-month contracts have the highest churn rate
* Customers with low tenure (0–12 months) are most likely to leave
* Higher monthly charges increase churn probability
* Customers without tech support or security services churn more
* Electronic check users show higher churn behavior

---

## 💡 Business Recommendations

* Improve onboarding experience for new customers
* Offer incentives for long-term contracts
* Bundle value-added services (tech support, security)
* Introduce loyalty discounts for high-paying customers
* Encourage automatic payment methods

---

## 🚀 Conclusion

This analysis demonstrates how customer churn can be reduced by leveraging data insights. The dashboard provides a clear, interactive way for stakeholders to understand customer behavior and make informed decisions.
